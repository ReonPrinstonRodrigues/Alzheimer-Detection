ML Methodology

A step-by-step walkthrough of our machine learning pipeline for Alzheimer's detection.

1
Data Collection

OASIS MRI Dataset

Loaded 86,437 brain MRI scan images from the OASIS dataset. Each image is resized to 224×224 pixels and converted to RGB format. Images are organized into 4 classes based on Alzheimer's severity.

Non Demented: 67,222
Very Mild: 13,725
Mild: 5,002
Moderate: 488
2
Data Cleaning

Quality Assurance

Removed corrupted and unreadable images using OpenCV validation. Filtered out non-image files and performed MD5 hash-based deduplication to eliminate duplicate scans. Pixel values normalized to [0, 1] range.

✓ Corruption check via cv2.imread
✓ Extension filter (jpg, jpeg, png)
✓ MD5 hash deduplication
✓ Pixel normalization → [0, 1]
3
Data Splitting

Stratified Train/Val/Test Split

Data split into 70% training, 15% validation, and 15% testing sets using stratified splitting to preserve class ratios across all sets. This ensures each split has proportional representation of all 4 classes.

Train 70%
Val 15%
Test 15%
4
Data Balancing

Handling Class Imbalance

Applied class weighting (sklearn's compute_class_weight) to give higher importance to minority classes during training. Additionally, real-time data augmentation is applied including rotation, flipping, zoom, and shift transformations.

ImageDataGenerator(
  rotation_range=20,
  horizontal_flip=True,
  zoom_range=0.15,
  width_shift_range=0.1,
  height_shift_range=0.1
)

5
Model Training

6 Deep Learning Models

Trained 6 different neural network architectures. Most were trained for 20 epochs using feature extraction with the Adam optimizer. The MobileNetV2 model was specifically fine-tuned by unfreezing its top 30 layers and trained with a lower learning rate (1e-4) for optimized performance. EarlyStopping and ReduceLROnPlateau callbacks ensure optimal training.
