================================================================================

Project Title   : Alzheimer's Disease Detection System
Domain          : Healthcare / Medical Image Classification
Technique       : Deep Learning (Convolutional Neural Networks & Transfer Learning)
Programming     : Python 3.12, TensorFlow 2.19, Flask

2. PROBLEM STATEMENT & PURPOSE
================================================================================

WHAT IS THE PROJECT?
--------------------
This project develops an AI-powered system that can analyze brain MRI
(Magnetic Resonance Imaging) scans and classify them into one of four stages
of Alzheimer's disease progression.

WHY AM I DOING IT?
------------------
Alzheimer's disease is the most common form of dementia, affecting over 55
million people worldwide. Early and accurate detection is critical because:

  * Early diagnosis allows patients to access treatments that can slow disease
    progression (e.g., Cholinesterase inhibitors, emerging immunotherapies
    like Lecanemab).
  * Manual diagnosis by radiologists is time-intensive, subjective, and prone
    to inter-observer variability — especially in the very early stages.
  * AI-assisted detection can serve as a second opinion tool, improving
    diagnostic accuracy and making screening accessible in resource-limited
    settings.
  * The distinction between "Very Mild Demented" and "Non Demented" stages is
    extremely subtle on MRI, making it an ideal candidate for deep learning.

WHAT IS THE PURPOSE?
--------------------
  1. Build a robust multi-class image classifier that can distinguish between
     four stages of Alzheimer's from MRI scans.
  2. Compare the performance of six different deep learning architectures
     (CNN, MLP, VGG16, ResNet50, EfficientNetB0, MobileNetV2) on this task.
  3. Deploy the best-performing model in a user-friendly web application
     that provides real-time predictions along with clinical context.
  4. Demonstrate that transfer learning with fine-tuning can achieve near-
     perfect accuracy (99.47%) on this medical imaging task.

HOW DID I DO IT?
----------------
  Step 1 : Collected the OASIS brain MRI dataset (86,437 images, 4 classes).
  Step 2 : Cleaned the data — removed corrupted images (0 found).
  Step 3 : Split the data into Train (70%), Validation (15%), Test (15%).
  Step 4 : Applied data augmentation (rotation, zoom, shear) and computed
            class weights to handle severe class imbalance.
  Step 5 : Trained 6 different models on Google Colab with a T4 GPU.
  Step 6 : Identified MobileNetV2 as the best base architecture.
  Step 7 : Fine-tuned MobileNetV2 with higher resolution (224x224) and
            partial backbone unfreezing, achieving 99.47% test accuracy.
  Step 8 : Built a Flask web application with user authentication, image
            upload, model selection, and detailed clinical result display.

4. METHODOLOGY
================================================================================

The project follows a structured 7-step machine learning pipeline:

  STEP 1 — PROBLEM ANALYSIS
    * Identified the task as multi-class image classification (4 classes).
    * Recognized challenges: class imbalance, subtle inter-class differences.

  STEP 2 — DATA COLLECTION
    * Downloaded dataset from Kaggle using the kagglehub API.
    * Organized images into class-labeled subdirectories.

  STEP 3 — DATA CLEANING
    * Validated all 86,437 images for readability (0 corrupted found).
    * Removed duplicate images using MD5 hash comparison.

  STEP 4 — TRAIN/VALIDATION/TEST SPLIT
    * Used stratified splitting (sklearn train_test_split) to maintain
      class proportions across all three sets.
    * Split ratio: 70% train / 15% validation / 15% test.

  STEP 5 — DATA AUGMENTATION & BALANCING
    * Applied real-time augmentation via Keras ImageDataGenerator:
        - Rotation: up to 20 degrees (10 degrees for fine-tuned model)
        - Zoom: up to 20% (10% for fine-tuned model)
        - Horizontal Flip: Yes (disabled for fine-tuned MRI model)
        - Shear: up to 20% (10% for fine-tuned model)
    * Computed inverse-frequency class weights using sklearn.

  STEP 6 — MODEL TRAINING
    * Trained 6 architectures using Keras Sequential API.
    * Used Adam optimizer with categorical crossentropy loss.
    * Applied EarlyStopping (patience=5-7) and ReduceLROnPlateau callbacks.

  STEP 7 — EVALUATION & COMPARISON
    * Evaluated all models on the held-out test set.
    * Generated classification reports, confusion matrices, and
      accuracy/loss training curves.
    * Selected the best model for deployment.

5. MODEL ARCHITECTURES
================================================================================

MODEL 1: CUSTOM CNN
-------------------
  Type        : Built from scratch
  Layers      : Conv2D(32) -> MaxPool -> BN -> Dropout(0.25)
                Conv2D(64) -> MaxPool -> BN -> Dropout(0.25)
                Conv2D(128) -> MaxPool -> BN -> Dropout(0.25)
                Flatten -> Dense(256) -> BN -> Dropout(0.5) -> Softmax(4)
  Parameters  : ~8.5M
  Input       : 128 x 128 x 3

MODEL 2: MLP (MULTI-LAYER PERCEPTRON)
--------------------------------------
  Type        : Fully connected (no convolutions)
  Layers      : Flatten -> Dense(512) -> BN -> Dropout(0.3)
                Dense(256) -> BN -> Dropout(0.3)
                Dense(128) -> BN -> Dropout(0.3) -> Softmax(4)
  Parameters  : ~25.3M
  Input       : 128 x 128 x 3

MODEL 3: VGG16 (TRANSFER LEARNING)
------------------------------------
  Type        : Pre-trained on ImageNet, frozen backbone
  Layers      : VGG16(frozen) -> GlobalAvgPool -> Dense(256) -> BN ->
                Dropout(0.5) -> Softmax(4)
  Parameters  : ~14.8M (trainable: ~66K)
  Input       : 128 x 128 x 3

MODEL 4: RESNET50 (TRANSFER LEARNING)
--------------------------------------
  Type        : Pre-trained on ImageNet, frozen backbone
  Layers      : ResNet50(frozen) -> GlobalAvgPool -> Dense(256) -> BN ->
                Dropout(0.5) -> Softmax(4)
  Parameters  : ~23.7M (trainable: ~66K)
  Input       : 128 x 128 x 3

MODEL 5: EFFICIENTNETB0 (TRANSFER LEARNING)
---------------------------------------------
  Type        : Pre-trained on ImageNet, frozen backbone
  Layers      : EfficientNetB0(frozen) -> GlobalAvgPool -> Dense(256) ->
                BN -> Dropout(0.5) -> Softmax(4)
  Parameters  : ~4.1M (trainable: ~66K)
  Input       : 128 x 128 x 3

MODEL 6: MOBILENETV2 (TRANSFER LEARNING — FINE-TUNED)  [BEST MODEL]
---------------------------------------------------------------------
  Type        : Pre-trained on ImageNet, partially unfrozen backbone
  Layers      : MobileNetV2(last 30 layers trainable) -> GlobalAvgPool ->
                Dense(256, ReLU) -> Dropout(0.5) -> Softmax(4)
  Total Params: 2,586,948 (9.87 MB)
  Trainable   : 1,855,364 (7.08 MB)
  Input       : 224 x 224 x 3
  Optimizer   : Adam (lr=1e-4)

13. CONCLUSION
================================================================================

KEY FINDINGS:
  1. Transfer learning with fine-tuning vastly outperforms training from
     scratch on medical imaging tasks with limited and imbalanced data.

  2. MobileNetV2 with partial backbone unfreezing (last 30 layers) achieved
     99.47% test accuracy — near-perfect classification across all 4 stages.

  3. Input resolution matters significantly: increasing from 128x128 to
     224x224 improved MobileNetV2's accuracy by +24.20 percentage points.

  4. Models trained from scratch (CNN, MLP) and some frozen transfer
     learning models (EfficientNetB0) completely failed to converge,
     highlighting the difficulty of this task without fine-tuning.

  5. The fine-tuned model achieved:
       - 99% precision and recall across ALL classes
       - Perfect 1.00 F1-score on the rarest class (Moderate Dementia,
         only 73 test samples)
       - Only ~41 misclassifications out of 12,966 test images

  6. Class weighting effectively addressed the 138:1 imbalance ratio
     between the majority and minority classes.

LIMITATIONS:
  * The model is trained on a single dataset (OASIS) and should be
    validated on external datasets before clinical deployment.
  * MRI preprocessing (skull stripping, normalization) was not applied,
    which could further improve performance.
  * The system is designed for educational purposes and should NOT be
    used as a substitute for professional medical diagnosis.

FUTURE WORK:
  * Implement Grad-CAM visualization to show which brain regions the
    model focuses on for each prediction.
  * Add support for 3D volumetric MRI analysis (currently 2D slices).
  * Validate on external datasets (ADNI, MIRIAD).
  * Implement model ensemble for improved robustness.
  * Add prediction confidence calibration.
